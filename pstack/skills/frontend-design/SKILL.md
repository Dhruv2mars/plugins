# Frontend design

Follow the user's brief and the existing product's design language. For a new direction, ground typography, color, layout, imagery, and motion in the subject and audience. Make a coherent choice and implement it; a design plan does not require a separate approval step unless the user asks for one.

Use real content where available. Let structure express the content, and use decoration and motion when they serve the page. Keep interface copy specific to what users can do.

Check the rendered result at relevant screen sizes. Fix visible layout problems, keyboard-focus issues, and motion that ignores reduced-motion preferences. Scale exploration and validation to the requested change; a small UI fix does not need a new design system or multiple concepts.
